# Servo the Robot Arm — Image Generation Prompts

Paste each prompt into an AI image generator (ChatGPT/DALL-E, Midjourney, Stable Diffusion, or similar), one pose per request, in the same chat so the style stays consistent. Generate at 1024x1024, save each result under the filename shown, then trim the padding (see the end of this file).

Always put this text at the start of the conversation:

```
I am about to ask you to generate seven different poses for a book mascot.
Please use a consistent drawing style for all seven images.
```

## Trim the Padding

AI generators add transparent padding that makes the mascot look too small at 90 px. After saving the seven PNGs into `docs/img/mascot/`, run this from the project root:

```bash
for f in neutral welcome thinking tip warning encouraging celebration; do
  python "$BK_HOME/src/image-utils/trim-padding-from-image.py" docs/img/mascot/$f.png
done
```

If an image has a white or checkered background instead of transparency, remove it first with `$BK_HOME/src/image-utils/floodfill-transparent.py`.
