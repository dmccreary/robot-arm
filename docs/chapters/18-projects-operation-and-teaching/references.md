# References: Projects, Operation, and Teaching

1. [Capstone course](https://en.wikipedia.org/wiki/Capstone_course) - Wikipedia - Describes the culminating, integrative project that ends a program of study. It frames the chapter's capstone scoping advice and the color-sorting project that pulls the whole book together.

2. [Rubric (academic)](https://en.wikipedia.org/wiki/Rubric_(academic)) - Wikipedia - Explains scoring guides, their criteria, performance levels, and how to build them. It supports the chapter's assessment rubric for judging student arm projects fairly and consistently.

3. [Robot ethics](https://en.wikipedia.org/wiki/Robot_ethics) - Wikipedia - Surveys the ethical questions raised by robots, including risks to people and how robots should be designed to behave well. It supports the chapter's responsible robotics section.

4. Mindstorms: Children, Computers, and Powerful Ideas (2nd Edition) - Seymour Papert - Basic Books - Papert originated constructionism and the idea of objects-to-think-with, using the programmable Logo turtle. His approach explains why students learn control and geometry best by building and debugging a physical robot.

5. Invent to Learn: Making, Tinkering, and Engineering in the Classroom (2nd Edition) - Sylvia Libow Martinez and Gary Stager - Constructing Modern Knowledge Press - Extends Papert's constructionism into practical classroom and makerspace guidance, including project-based assessment and open-ended challenges. It informs the chapter's lab schedules and makerspace advice.

6. [SO-ARM100 and SO-101 Repository](https://github.com/TheRobotStudio/SO-ARM100) - The Robot Studio, GitHub - The open-source design files, bill of materials, and printing guidance for the SO-100 and SO-101 arms. It is the source for the group parts orders and replacement parts discussed here.

7. [SO-101 Assembly and Calibration](https://huggingface.co/docs/lerobot/so101) - Hugging Face LeRobot Docs - Official steps for configuring motors, assembling joints, and calibrating leader and follower arms. It backs the chapter's startup procedures, servo replacement, and recalibration after maintenance.

8. [Logging HOWTO](https://docs.python.org/3/howto/logging.html) - Python Documentation - A tutorial on log levels, file handlers, and formatting in the standard library. It supports the chapter's monitoring and run-log practices for an arm that runs unattended.

9. [How to Contribute to Open Source](https://opensource.guide/how-to-contribute/) - GitHub Open Source Guides - Explains how to find a project, file useful issues, and submit pull requests, including non-code contributions. It guides students toward the chapter's open-source contribution goals for arm projects.

10. [Open Source Hardware Definition](https://oshwa.org/resources/open-source-hardware-definition/) - Open Source Hardware Association - Sets out the criteria that make physical designs open, so others can study, modify, build, and sell them. It explains the licensing culture behind arms like the SO-101 and responsible sharing.
